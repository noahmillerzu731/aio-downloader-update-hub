## Troubleshooting Guide

### Nothing happens when I start the download

Test the network connection and reload the download page. If the problem remains, look through the repository for a newer build or relevant instructions.

### Required files cannot be reached

Make sure the system has network access and that local security or network restrictions are not preventing the downloader from connecting. The source may also be temporarily unavailable, so trying again later can help.

### The downloaded mods are missing in Minecraft

First, confirm that the downloader finished without interruption. Then check the project instructions for the required file location and any setup steps that must be completed.

### Files cannot be saved

Inspect the permissions on the destination directory. Use a location where the current user is allowed to create and modify files.

### An earlier download creates problems

Inspect the files left by the downloader and move or delete incomplete items before retrying. Back up any files that may be needed before changing the local setup.

### The build is not suitable for my Minecraft setup

The available project profile does not list compatibility details. Review the repository documentation and the information associated with the specific build before using it.
